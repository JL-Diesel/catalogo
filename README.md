# Catálogo JL Diesel

Catálogo de repuestos para los vendedores de Repuestos JL Diesel C.A.

- Los precios, las existencias y las fotos se leen de la hoja de Google configurada en `config.js` (pestañas "Lista de precios" y "Fotos").
- La página se puede instalar en la tablet y funciona sin internet con la última lista descargada.
- Se publica con GitHub Pages desde la rama `main`.
